# 心仔 · 给娃娃一颗糖心

把一起走过的日常，变成它记得的回忆。面向棉花娃娃爱好者的「共同回忆＋轻陪伴」App，采用奶油色界面，包含照片回忆、出行轨迹、娃娃档案与城市护照。

当前版本 **0.2.0**：Android 本地混合应用（WebView 界面＋Java 原生能力），同时保留浏览器设计预览。安卓运行不需要启动网站服务器。

## 已实现

- 娃娃名字、生日、陪伴性格，首次使用引导。
- 照片回忆的新建、编辑、删除、搜索与日历回看；心情、城市、奶油／粉色／票根模板。
- 从已保存城市生成护照印章，基于本地回忆的轻陪伴文案。
- 安卓系统照片选择、PNG 卡片导出、JSON 备份导入导出。
- 主动授权后采集手机真实位置，前台服务记录、暂停／继续、旅程恢复与 GPX 导出。
- 安卓蓝牙扫描、用户选择连接、GATT 服务发现；设备提供标准电量服务时读取电量。
- 本机私有文件保存、系统返回键、状态栏与键盘适配、手机触感反馈。

## 仍待硬件联调的部分

糖心目标硬件使用独立 GNSS＋BLE：离开手机仍记录，重新靠近后同步。当前还没有硬件固件、定制服务 UUID 或离线轨迹同步实现。通用蓝牙连接成功不代表已经能接收任意定位器的轨迹。

当前实际轨迹来自手机定位；路线是 WGS84 点绘制的形状，没有地图街道底图、地址搜索或坐标转换。浏览器中的蓝牙／旅程仍为演示。无账号、云同步、在线 AI、支付或远程追踪。

照片与位置未做应用层加密；清除数据或卸载会丢失本机回忆。请使用 JSON 导出备份。安卓版本暂为开发测试包，未上架应用商店。

## 安卓构建与安装

见 [安卓迁移与安装说明](docs/安卓迁移与安装说明.md)。可用 Android Studio 打开 `android/`；仓库提供 Windows PowerShell 7 构建脚本。APK、SDK 缓存和签名密钥不提交到仓库。

## 浏览器预览

安装 Node.js 22 或更新版本，无 npm 依赖：

```sh
npm start
```

打开 <http://127.0.0.1:4173>。服务仅监听本机。语法检查运行 `npm run check`。

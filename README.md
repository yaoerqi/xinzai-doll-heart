# 心仔 · 给娃娃一颗糖心

把一起走过的日常，变成它记得的回忆。面向棉花娃娃爱好者的「共同回忆＋轻陪伴」App，采用奶油色界面，包含照片回忆、出行轨迹、娃娃档案与城市护照。

当前版本 **0.5.0**：Android 本地混合应用（WebView 界面＋Java 原生能力），同时保留浏览器设计预览。安卓运行不需要启动网站服务器。

## 0.5 新增

- XIAO nRF52840 + LC76G 实时 BLE 固件，校验 NMEA 后发送定位状态和有效坐标。
- 安卓订阅专用定位服务，显示搜星、有效位置、无数据及数据过期状态。
- 旅程可选糖心卫星定位或手机定位，硬件来源通过连接设备前台服务记录，断连与定位失效保留路线缺口。
- 备份保留硬件来源、质量和分段；不提供设备离线补传。
- 固件编译及 XIAO 烧录已完成；真实安卓 BLE 联调、锁屏接收、室外有效坐标和电池续航仍待验收。详见 [固件与协议说明](firmware/xinzai_ble/README.md)。

## 已实现

- 娃娃名字、生日、陪伴性格，首次使用引导。
- 照片回忆的新建、编辑、删除、搜索与日历回看；心情、城市、奶油／粉色／票根模板。
- 从已保存城市生成护照印章，基于本地回忆的轻陪伴文案。
- 安卓系统照片选择、PNG 卡片导出、JSON 备份导入导出。
- 主动授权后采集手机真实位置，前台服务记录、暂停／继续、旅程恢复与 GPX 导出。
- 安卓蓝牙扫描、用户选择连接、GATT 服务发现；设备提供标准电量服务时读取电量。
- 本机私有文件保存、系统返回键、状态栏与键盘适配、手机触感反馈。

## 0.4 新增

- 多娃娃：最多 20 个档案，分别保存名字、生日和性格；切换后独立显示回忆、日历、统计和城市护照，可归档与恢复。
- 多图相册：每份回忆最多 9 张照片，支持多选、压缩、设封面、前移、移除、逐张查看和拼图卡片导出。
- 云同步：邀请码注册、账号登录、主动同步与前台自动同步；包含全部娃娃、回忆、多图、回收站和已保存路线。并发修改保留副本，永久删除跨设备同步。
- 配套 Node.js＋SQLite 服务、Docker Compose 和 Caddy HTTPS 配置；安卓凭据由 Android Keystore 加密保存。旧单娃娃／单图数据及 v1 备份可迁移，导出升级为 v2。

云服务代码已提供，**没有预置的公网服务**。先按 [云同步部署与 0.4 使用说明](docs/云同步部署与0.4使用说明.md) 部署，然后在 App「我的 → 连接云同步」填写 HTTPS 地址。离线功能不需要部署服务器。

## 0.3 已有功能

- 一张照片或一句话即可保存，标题可自动生成；可选择保存后立即制作卡片。
- 编辑草稿自动保存在本机，关闭窗口、返回和重新打开后可以继续；照片选择的异步结果不会串入下一份回忆。
- 珍藏、照片、出门筛选，城市与心情组合筛选，跨城市／心情／地点／文字搜索。
- 日历支持前后月份、月份选择、回到本月和空白日期补记，正确处理闰年。
- 首页本月回顾、往年今日／过去回忆回看；来信引用真实记录，安静陪伴开关实际控制首页记录邀请。
- 删除先进入回收站，可恢复或明确永久删除，照片和路线一起处理；回收站不会自动清空。
- 备份预览、合并去重、同编号不同内容保留副本、明确确认后的替换导入；兼容原 v1 备份。
- 定位显示最后更新时间，记录中超过 60 秒没有新点标注过期；非记录中的未保存旅程可主动舍弃。
- 本地预览服务器只提供界面与图片资源，不再开放整个项目目录。

备份包含已保存回忆、照片、档案和回收站，不含编辑草稿及未保存旅程。导入前需要先处理草稿和当前旅程；合并保留本机档案，只合并正常回忆，替换则恢复备份档案和回收站。当前 JSON 备份上限 25 MB、回忆与回收站合计上限 500 份；容量不足时保持原内容并提示失败。

## 仍待硬件联调的部分

糖心目标：娃娃和手机一起携带，独立 GNSS 获取位置，通过 BLE 实时传给 App；第一版取消硬件离线轨迹保存与补传。0.5 已实现对应固件、定制服务 UUID 和安卓接收代码；通用蓝牙连接成功不代表已经能接收任意定位器的位置，整机表现仍需实机联调。

安卓可选手机或硬件来源；路线是 WGS84 点绘制的形状，没有地图街道底图、地址搜索或坐标转换。浏览器中的蓝牙／旅程仍为演示。未接入在线 AI、支付或远程追踪。

本机回忆和云端资料库未做应用层加密，不是端到端加密服务。清除数据或卸载会移除本机回忆；已成功同步的内容可登录原账号取回，未同步内容需依靠 JSON 备份。安卓版本暂为开发测试包，未上架应用商店。

## 浏览器预览

安装 Node.js 22 或更新版本，无 npm 依赖：

```sh
npm start
```

打开 <http://127.0.0.1:4173>。服务仅监听本机。语法检查运行 `npm run check`，数据规则回归检查运行 `npm test`。

浏览器端到端检查：在 Playwright 可用的环境中，先启动预览服务，再运行 `node tests/experience.browser.cjs` 和 `node tests/android-ui.browser.cjs`；新功能检查运行 `node tests/library-cloud.browser.cjs`，会启动临时服务并模拟两台设备，验证实际 HTTP 同步、冲突和多图。后者使用模拟原生桥接验证安卓界面逻辑，不代替真机 GPS／BLE 测试。脚本默认使用本机 Edge，无需给应用增加 npm 运行依赖。

在专用 Android 模拟器中安装并启动开发包后，可运行 `node tests/android-smoke.cjs`，直接检查 WebView 与原生私有文件持久化。脚本只接受 `emulator-*` 设备，并会在该模拟器生成测试回忆，不用于用户真实手机。

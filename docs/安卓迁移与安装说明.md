# 心仔 Android 0.2.0：安装与开发

## 当前交付

本项目是可离线运行的 Android 混合应用：界面文件打包进 APK，Java 层调用系统定位、BLE、文件选择和保存。无需网站服务器，不是桌面浏览器快捷方式；界面也没有重写成 Kotlin／Compose 原生控件。

- 应用名：心仔；包名：`com.xinzai.app`。
- 最低 Android 8.0（API 26）；目标 API 35。
- 开发测试包：`output/android/心仔-0.2.0-debug.apk`，仅在本地构建后存在，不提交 Git。
- 已做 Android 15 模拟器安装与启动验证；其他系统版本和国产手机系统仍需真机回归，最低版本声明不代表所有机型已测试。

## 安装到自己的安卓手机

1. 把 APK 通过 USB／文件传输发到手机。
2. 在手机文件管理器中打开 APK；按系统提示临时允许该文件来源安装应用。
3. 打开「心仔」，给娃娃起名，先体验记录照片和回忆。
4. 在「足迹」主动开始同行后申请精确位置权限。拒绝权限仍可手动记录回忆。
5. 在位置说明中可开启旅程状态通知；没有通知权限时，可回到 App 暂停／结束。

安卓系统或手机厂商的省电策略可能中断轨迹。请先做一次短途测试，查看暂停、继续和保存是否符合预期。该版本没有申请始终定位权限，没有开机自启。

已有同包名但签名不同的版本不能直接覆盖。卸载会移除本机回忆，请先导出 JSON 备份。后续正式发布需建立持续保管的正式签名方案；不要把密钥放进仓库。

开发机已安装 Android SDK Platform Tools 时，也可用：

```sh
adb install -r output/android/心仔-0.2.0-debug.apk
```

## Windows PowerShell 构建

需要 PowerShell 7、JDK 11 或兼容新版 JDK；将 `JAVA_HOME` 设为 JDK 安装目录。需要下载 Google 官方 Android SDK，网络不通时改用 Android Studio 的 SDK Manager。

在仓库根目录执行：

```powershell
# JAVA_HOME 指向自己的 JDK 目录，不包含末尾的 bin。
./scripts/prepare-android-tools.ps1
./scripts/build-android.ps1
```

准备脚本读取 Google SDK 仓库索引，下载指定平台、构建工具、adb 并校验索引中的 SHA-1。工具缓存在 `.tooling/`，不提交到 Git。

构建脚本：复制网页资产 → aapt2 资源编译 → javac → D8 → 打包 → zipalign → 本地开发签名 → 校验签名与对齐。首次构建会生成仅供调试的密钥。输出 APK 放在 `output/android/`。

Windows aapt2 对非 ASCII 路径存在兼容问题，脚本在临时目录中新建独立构建目录；如电脑的临时目录含中文，可将 `TEMP` 指向自己创建的 ASCII 路径。构建结束后可删除本次 `xinzai-android-build-*` 临时目录。

默认构建脚本在 JDK 11 下验证过。使用 Gradle 工程时则需 AGP 8.7.3 对应的 **JDK 17、Gradle 8.9、Android SDK 35**。仓库未附 Gradle wrapper；可在安装 Gradle 8.9 后进入 `android/` 执行 `gradle wrapper --gradle-version 8.9`，再导入 Android Studio 或执行 `./gradlew assembleDebug`。原生层无额外第三方运行时库。

## 数据与能力边界

| 功能 | 现状 |
|---|---|
| 照片、档案、回忆 | 本地私有文件，原子写入；无云备份，未做应用层加密 |
| JSON 备份、PNG 卡片、GPX | 使用系统文件保存界面；取消操作不会删除回忆 |
| 手机轨迹 | 前台定位服务，分段记录；中断后可从已落盘数据恢复 |
| 路线展示 | 根据 WGS84 位置点绘制折线，无街道底图或自动地址识别 |
| BLE | 扫描、连接、服务发现；标准电量服务视设备支持情况读取 |
| 糖心离线轨迹 | 只有协议草案，硬件固件与 BLE 同步待到货联调 |
| 心跳触感 | 当前振动发生在手机，未控制娃娃中的马达 |
| 陪伴文字 | 本地规则与模板，不是云端 AI 或真人回复 |

定位数据不是远程防丢服务。GNSS 硬件采样与手机采样会作为不同来源保存，不能把手机记录误称为娃娃独立采集。

## 开发检查

```sh
npm run check
```

UI 可通过 `npm start` 在本机预览；浏览器不能验证 Android 原生权限和硬件 API。安卓应至少回归：首次建档、系统相册选择、权限允许／拒绝、轨迹暂停／继续、后台中断恢复、导出保存／取消、系统返回键、离线启动和蓝牙关闭场景。

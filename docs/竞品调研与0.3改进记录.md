# 心仔 0.3：竞品调研与改进记录

日期：2026-10-04。产品方向继续采用「共同回忆＋轻陪伴」。定位硬件维持近距离 BLE 实时传输方案，不恢复硬件离线日志、补传或蜂窝网络需求。

## 参考产品与取舍

本轮根据官方产品页面、开发者发布说明和帮助文档调研，未把这些产品逐一下载安装到真机横向测评。以下优点是公开功能与设计思路，不代表已经验证其全部实际体验。

|---|---|---|

## 代码检查发现与已落地修复

1. **编辑容易丢失**：原来关闭弹窗就丢失尚未保存的内容。现在输入后自动存草稿，关闭、安卓返回、页面离开前再次保存；重开可继续或明确舍弃。照片压缩后也入草稿。写入失败会提示，保留编辑窗口和已提交的数据。
2. **记录门槛偏高**：原来强制起标题。现在选一张照片或写一句话即可，缺少标题时按日期生成；全空记录仍会被拦截。可以选择保存后进入卡片制作。
3. **找回过去记录困难**：补城市／心情组合筛选，珍藏、照片、出门分类，并保留关键词搜索。编辑已有回忆时保留珍藏和路线。
4. **日历局限于一个月**：新增指定月份与前后月份导航、回到本月、日期数量、当天标记和空白日期补记。验证日期真实性，防止导入 2 月 31 日等异常值。
5. **陪伴开关没有实际作用**：开启安静陪伴时不显示记录邀请；来信从已保存回忆中选取标题和日期，结合娃娃性格生成本地文案，不再编造用户没记录过的经历。
6. **记录后缺少回看理由**：首页展示本月回忆数量与记录天数，一键查看本月；有往年同日记录时展示「往年今日」，没有时展示真实过去回忆，并明确区分。
7. **删除无法反悔**：改为回收站，文字、照片、路线一起恢复，永久删除需要再次确认；不自动清空。
8. **备份只能覆盖且恢复风险高**：新增导入前预览、合并去重、冲突保留副本、明确确认替换。导入会校验照片格式、字段长度、真实日期、轨迹经纬度与时间顺序。导出前同样校验，避免生成自己无法导回的文件。
9. **定位状态容易被误解**：展示最后定位时间，记录中超过 60 秒未更新标注过期；保留手机来源标识。未保存且已停止的旅程可主动舍弃。旧版离线硬件说明已移除。
10. **移动端阅读与误操作**：提高表单、卡片文字和触控尺寸，增加键盘焦点和减少动态效果支持。异步照片处理绑定当前编辑器，避免关窗后照片串入下一份回忆。
11. **预览服务暴露项目文件**：原服务能通过本机 URL 读取目录中的任意文件。现在使用界面资源白名单，拒绝访问 Git 配置、项目文档等非预览资源。

## 数据与升级

- 保持包名 `com.xinzai.app`，版本号升为 `0.3.0`／versionCode 3，沿用本机原有开发签名。
- 未迁移或清空用户原 `xinzai-v1` 存储。新增字段有默认值；原 v1 备份可导入。
- 备份包含已保存的回忆、照片、娃娃档案和回收站。编辑草稿、未保存旅程不包含在备份中。
- 合并保留本机档案、回收站和已有记录；只导入备份中的正常回忆。完全替换恢复备份档案与回收站，需要明确确认。
- JSON 备份上限 25 MB，正常回忆与回收站合计最多 500 份。当前仍采用整体 JSON 存储，大规模相册、数据库迁移与分卷备份留待后续设计。
- 建议安装新版前导出旧版备份，不卸载旧版。若原安装包签名不同，应先确认升级路径，避免卸载造成数据丢失。

## 验证与实际边界

- 数据规则测试：旧备份兼容、闰年日期、恶意或异常数据拒绝、合并冲突与去重、回收站编号碰撞、组合筛选、回看选择和备份往返。
- 浏览器端到端：草稿恢复、自动标题、保存后卡片、珍藏编辑保留、回收站恢复、搜索、月份补记、导入去重与冲突、储存失败回滚、照片处理与 PNG 导出、移动与桌面布局、预览文件访问隔离。
- 安卓桥接契约检查使用模拟桥：验证过期定位、完成旅程附属路线、硬件未适配说明和安卓返回键草稿。不能据此宣称真实硬件已连接。
- APK 已构建，通过 v2／v3 签名与 ZIP 对齐验证，已在 Android 15 模拟器安装并启动。直接连接模拟器 WebView，验证原生版本号、草稿写入 App 私有文件、恢复与正式保存、重新加载后的持久化和界面布局。
- 实际手机上的权限、后台省电、真实 BLE／GPS 精度与续航仍需实测。模拟器检查不代表物理硬件定位链路已通过。

本轮不加入云账号、云同步、在线 AI、多娃娃切换、多图相册、地图厂商 SDK 或独立硬件固件。现有能力先围绕「记录得下、找得到、不轻易丢失、愿意回看」补齐；本地回忆尚未做应用层加密。

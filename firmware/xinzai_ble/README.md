# XIAO + LC76G 实时蓝牙固件 0.5

目标板：Seeed XIAO nRF52840 普通版。使用 Seeed nRF52 Boards 1.1.13，FQBN `Seeeduino:nrf52:xiaonRF52840`。将本目录 `.ino` 和 `NmeaState.h` 一起放入 Arduino 草稿目录后编译。ESP32 系列不能直接使用这份 Bluefruit 固件。

## 接线与使用

LC76G 完整开发板 VCC → XIAO 3V3，GND → GND，TX → D7/RX，UART 115200。当前验证使用 USB 电源；电池另行核对。换线前断电。三节 AA 电池盒不接 BAT/3V3。

蓝牙名称为 `XinZai-Heart`。安卓 0.5 扫描、连接后订阅位置通知；足迹中主动选择“糖心卫星定位”开始保存路线。室内无定位时仅显示搜星，不记录虚构坐标。硬件不存储历史轨迹，不补传断连期间的位置。

## 协议 V1

Service UUID：`6f8a0001-7b2d-4c6a-9f41-8e65c0d2a901`。

Read/notify characteristic：`6f8a0002-7b2d-4c6a-9f41-8e65c0d2a901`。每秒 20 字节，小端，不需要 MTU 协商。位置不进入广播包。

| 偏移 | 长度 | 内容 |
|---|---|---|
| 0 | 1 | 0x58 |
| 1 | 1 | 协议版本 1 |
| 2 | 1 | bit0：近期有校验通过的 NMEA；bit1：位置有效；其他位为 0 |
| 3 | 1 | GGA 参与定位卫星数，不是可见卫星数 |
| 4 | 2 | uint16 序号，允许回绕 |
| 6 | 4 | int32 纬度 × 10^7，WGS84 |
| 10 | 4 | int32 经度 × 10^7，WGS84 |
| 14 | 2 | HDOP ×100；65535 为未知，不代表米级精度 |
| 16 | 2 | RMC 数据年龄，秒；65535 为无有效 RMC |
| 18 | 2 | 前 18 字节 CRC-16/CCITT-FALSE（初值 0xffff，多项式 0x1021） |

有效坐标要求 RMC=A、GGA 定位类型为 1/2/4/5、两者 UTC 秒一致且年龄≤2.5秒、参与定位≥4颗、HDOP≤10、度分及经纬度范围合法。无效时坐标字节为 0，接收端必须检查有效标志，不能仅用 (0,0) 判断。

安卓丢弃损坏、重复、倒序和不支持版本的包；超过5秒无新包清除实时坐标。每约4秒保存一个有效点，暂停、无定位、断连和超过10秒采样缺口分段。硬件路线时间使用手机接收时刻减报文年龄，标记 `timeSource=phone-reception`，并非卫星 UTC。

## 验证与边界

2026-10-14：XIAO 实物解析自检43项通过，`tests/HeartPacketTest.java` 20项检查通过（含实物发出的跨语言测试向量）；正式固件已编译、烧录，USB读回 `nmea=1 fix=0`。室内曾在原始NMEA看到1颗可见GPS卫星，但尚未完成有效定位。浏览器界面测试用独立测试数据，不代表安卓真机BLE验收。

自检草稿位于 `firmware/nmea_self_test`，编译时把本目录 `NmeaState.h` 复制到自检草稿旁。该程序不启动BLE，运行后需重新烧录正式固件。

真实安卓蓝牙通知、锁屏持续接收、断连重连、室外有效坐标、电池与功耗均仍待验收。当前开发样机GATT未加入配对认证和所有权绑定；仅用于自有设备联调，不能视为量产成品。没有电量测量，不虚构电池百分比。
